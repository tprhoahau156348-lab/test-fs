# Jan Oblak fan page

 אפליקציית stack-full קטנה עם אימות

## מה יש באפליקצייה

1. עמוד Login / Sign Up
   • טופס להתחברות עם פרטי משתמש קיימים, ודרך להרשמה כמשתמש חדש
   • לאחר התחברות/הרשמה מוצלחת, המשתמש מועבר לעמוד הפרופיל שלו
2. עמוד פרופיל
   • מציג את פרטי המשתמש המחובר (שם ואימל)
   • משתמש מנותק שמגיע ישירות ל-URL הזה, יועבר מייד לעמוד התחברות ולא יוכל לראות את התוכן של העמוד הזה 
   • כולל כפתור ניתוק / out Log שמנקה את ה storage-local ומחזיר את המשתמש לעמוד ההתחברות.

## הוראות הרצה

### צד שרת

1. לפתוח את הטרמינל בתיקיית השרת (server)
2. להתקין את החבילות (אם עוד לא הותקנו):

   ```bash
   npm install
   ```
3. להריץ את השרת:

   ```bash
   node server.js
   ```

### צד לקוח

1. לפתוח טרמינל נוסף בתיקיית הלקוח (client)
2. להתקין את החבילות (אם עוד לא הותקנו):

   ```bash
   npm install
   ```
3. להריץ:

   ```bash
   npm run dev
   ```
